# Climate Portfolio — Standing Orders

## Who I am
I'm a climate finance professional building consulting-grade deliverables. I have no coding background. Explain what you're doing in plain English as you work. Never assume I know technical terms — define them when you use them.

## How to work with me
Before any multi-step task, show me a short plan and wait for my go-ahead. Take small steps, not big one-shot builds. Never invent numbers or data — every figure needs a source next to it. If something is unverified, write UNVERIFIED next to it.

## Where files go
data/ for all raw and cleaned inputs. analysis/ for all scripts and code. deliverables/ for final outputs only.

## Obsidian logging
When I say "log it", check if a session note for today already exists at ~/Desktop/Second Brain/01- Projects/Climate Curriculum/Sessions/YYYY-MM-DD.md. If it does, append a new numbered session block at the bottom (Session 2, Session 3, etc). If it doesn't exist yet, create it with Session 1. Never overwrite or delete existing content in that file. Each session block should cover: what we built, decisions made and why, new terms for my glossary, and what the next step is.
